# To-do-list
TaskFlow - Task Management Website

📌 Description

TaskFlow is a simple and responsive Task Management Website that helps users organize their daily tasks and keep track of deadlines.

Users can create tasks, set a required due date, mark tasks as completed, edit existing tasks, delete tasks, and filter tasks according to their status.

The project is designed with a clean and modern interface that works on desktop, tablet, and mobile devices.

---

✨ Features

- ➕ Add new tasks.
- 📅 Set a required due date for every task.
- 🚫 Prevent adding tasks without a due date.
- ✅ Mark tasks as completed.
- ✏️ Edit existing tasks.
- 🗑️ Delete tasks.
- 🔍 Filter tasks by status.
- 🟡 Display pending tasks.
- 🟢 Display completed tasks.
- 🔴 Automatically detect overdue tasks.
- 💾 Save tasks using "localStorage".
- 📱 Responsive design for different screen sizes.
- 🎨 Modern and consistent UI design.

---

📊 Task Status

Each task can have one of three statuses:

🟡 Pending

The task has not been completed and its due date has not passed.

🟢 Completed

The task has been marked as completed.

🔴 Overdue

The due date has passed and the task has not been completed.

🚀 How to Run

1. Download or clone the repository.

2. Open the project folder.

3. Open "index.html" in your browser.

4. For the best development experience, use a local development server such as Live Server.

---

💾 Data Storage

TaskFlow uses the browser's LocalStorage to save tasks.

This means tasks remain available even after refreshing or closing the browser, as long as the browser's local storage has not been cleared.
